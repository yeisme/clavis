## 1. 可拖动分割视图规格（剪贴板左右分栏）

### 1.1 现状问题（核对 `1-clipboard.webp`，`720×536 pt`）

1. **左右比例严重倒挂**：左侧列表占约 `420 pt`（~`58%`），而标题与来源仅消耗左半边空间，右半边整列大面积留白；右侧预览卡片被压缩至约 `265 pt`（~`37%`），扣除圆角外框与内边距后图片画布净宽仅约 `225 pt`（`450 px @2x`），导致 `3304×1782` 宽屏截图缩成不可辨认的细条。
2. **缺少拖动分隔条且外壳冗余**：左右两区靠空白缝 + 独立圆角大卡片隔开，白白损耗约 `28 pt` 横向空间，用户无法按需拉宽预览区看长代码或大图。
3. **缩放栏「适应」重复**：顶部控件依次为 `[适应](蓝胶囊)`、`[-]`、`适应`、`[+]`、`[原始尺寸]`，激活按钮与读数文本重复打印「适应」，未显示真实缩放百分比（如 `14%`）。
4. **底栏元信息与操作按钮重叠**：左下 `3304×1782 · 1.3 MB` 与右下 `[⌘I 预览]` 按钮发生字面碰撞（`1.3 MB` 直接被按钮压住），原因是预览列过窄且元信息与两个操作胶囊强塞在同一行。

### 1.3 Clavis 剪贴板可拖动分割视图落地数值表

**结构改造原则**：取消右侧预览区的独立圆角外框，改用 **Apple 风格通栏 `1 px` 垂直发丝线分割**（左列表 `surface.content` + 右预览 `surface.content`，中间 `1 px` `border.hairline`），瞬间回收 `28 pt` 横向空间，并将**默认比例由 58:42 翻转为 38:62**（在 `720 pt` 宽窗下：左 `274 pt`、右 `446 pt`；若窗口放大至 `860 pt`，右预览净宽可达 `530 pt` = `1060 px @2x`）。

#### A. 分隔条三态与交互规格

| 属性 | Normal（常态） | Hover（悬停） | Dragging（拖动中） |
|---|---|---|---|
| **视觉线宽** | `1 px`（Retina 物理 `1px`） | `2 pt`（居中覆盖在 `1px` 线上） | `2 pt` |
| **命中热区宽度（Hit Target）** | `8 pt`（以发丝线为中心左右各 `4 pt`） | `8 pt` | 全局 pointer capture，离开热区不丢拖 |
| **颜色（Light / Dark）** | `#000000` @ `0.09` / `#FFFFFF` @ `0.11` | `#0A84FF` @ `0.55` | `#0A84FF` @ `1.00` |
| **延迟与过渡** | — | 悬停停留 `150 ms` 后亮起（防鼠标划过闪烁）；`100 ms ease-out` | 即时（`0 ms`），松手 `100 ms` 退回常态 |
| **鼠标光标（macOS）** | 默认 | `NSCursor.resizeLeftRight`（`col-resize`）；贴左限切 `resizeRight`，贴右限切 `resizeLeft` | 锁定 `resizeLeftRight` |

#### B. 比例约束、复位与持久化

| 规格项 | 数值 / 规则 | 说明 |
|---|---|---|
| **推荐剪贴板窗口默认尺寸** | `780 × 540 pt`（兼容现行 `720 × 536 pt`） | 宽窗让大图/代码预览一眼可读；支持记忆窗口尺寸 |
| **默认分栏比例（左 : 右）** | **`38% : 62%`** | `720 pt` 时左 `274 pt` / 右 `446 pt`；`780 pt` 时左 `296 pt` / 右 `484 pt` |
| **左栏最小 / 最大宽度** | 最小 `220 pt`（保证图标 + 10 汉字标题不截断）；最大 `50%` 窗宽 | 防止右栏预览被再次挤成细条 |
| **右栏最小宽度** | 最小 `320 pt`（保证缩放条 + 底部按钮永不碰撞） | 双边取严：`leftW = clamp(raw, 220, winW - 320)` |
| **双击复位** | 双击分隔条 `8 pt` 热区 → 平滑复位至 `38% : 62%`（`140 ms ease-out`） | 同步提供快捷键 `⌘\` 折叠/展开右侧预览 |
| **持久化** | 存用户配置 `clipboard.split_ratio`（浮点 `0.38`）与 `clipboard.preview_visible`（布尔 `true`），拖动 `mouseup` 后防抖 `300 ms` 落盘 | 跨重启与跨分辨率按比例还原，不存死像素 |

#### C. 预览画布缩放与「防重复 / 防重叠」修补规格

| 区域 | 落地规格 | 解决的截图问题 |
|---|---|---|
| **图片画布缩放算法** | 默认 **`aspect-fit`（按容器等比完整适配，不放大超原图）**：`scale = min(1.0, (canvasW - 24) / imgW, (canvasH - 24) / imgH)`，随分割条拖动**实时重算**；切到「原始尺寸 `1:1`」或手动 `+/-`（步进 `25%`，范围 `10%–400%`）后开启平移/滚动，画布内边距固定 `12 pt`，底色 `#F5F5F7`（Light）/ `#141415`（Dark）+ `1 px` 内发丝线 | 彻底解决 `3304×1782` 窄画布看不清的问题，拉宽右侧即可实时放大 |
| **顶部缩放控件（去重）** | 收敛为单一 macOS 分段胶囊（高度 `24 pt`，圆角 `6 pt`，底 `#000000` @ `0.05`）：`[ - ]  14%  [ + ]` + 右侧独立 `[适应]` / `[1:1]` 切换（仅激活项高亮）。**禁止再在中间重复打印「适应」文字**，中间永远显示真实百分比（`tabular-nums`，`11 pt`），点击百分比直接回切「适应」 | 根除「适应」出现两次的 Bug |
| **底栏信息与动作分层（防重叠）** | 拆为**独立两行**（中间用 `1 px` `border.hairline` 隔开）：<br>① **元数据行**（高 `28 pt`，左右内边距 `12 pt`，`11 pt` `#6E6E73` 等宽数字）：左 `3304×1782 · 1.3 MB · PNG`，右 `来自 Microsoft Edge · 3 分钟前`（宽不足时优先截断来源名，绝不压数字）；<br>② **主动作栏**（整窗底部统一 `36 pt` 共享底栏，或右栏独立 `36 pt` 底栏）：右对齐 `[⌘I 快速预览]`（中性灰描边胶囊）+ `[⌘K 动作]`（主操作按钮），两按钮间距 `8 pt` | 彻底消除 `1.3 MB` 被 `⌘I 预览` 压住的重叠 Bug |

## 2. 子菜单面板高度规格（Leader 与命令面板 push/pop）

### 2.1 现状问题（核对 `2-leader-submenu.webp` 与 `3-leader-main.webp`）

- 在实际运行中，进入 `Leader › AI 改写`（仅 2 个动作：`p 润色`、`t 中英互译`）时，浮窗沿用了固定/全屏高度，导致 2 行动作下方出现大片无意义空白；
- 对比截图实测：`3-leader-main.webp`（5 项）内容高 `346 pt`，`2-leader-submenu.webp`（2 项）裁切内容高 `202 pt`——单行采用独立描边卡片（高约 `42 pt` + 间距 `6 pt` = `48 pt/项`），当主窗与子页未建立统一的「内容驱动高度 + 平滑过渡」协议时，要么子页留白失控，要么来回 push/pop 时整窗剧烈跳动。

### 2.2 同类产品做法与一手来源

| 产品 | 做法核实 | 官方来源 |
|---|---|---|
| **Raycast（Root / Push Navigation）** | 根搜索空输入时为紧凑单行搜索条，出现结果或进入 `List` / `Detail` 等子视图时窗口展开至标准列表高度；子视图通过 `useNavigation()` `push` / `pop`（`Esc` 返回）在同窗内切换，视觉上保持顶边锚定不漂移。*注：Raycast 针对 2 条目子列表是否收缩窗口的精确像素策略官方文档未公开 → **未验证**。* | [Raycast API — Navigation](https://developers.raycast.com/api-reference/user-interface/navigation)<br>[Raycast API — List](https://developers.raycast.com/api-reference/user-interface/list) |
| **Alfred（主浮窗 & Workflow 子列表）** | 主浮窗与 Workflow Script Filter 列表采用**内容自适应高度（随匹配条目数 0 → N 动态伸缩，达最大可见条数后内部滚动）**，窗口顶部锚定在屏幕上方固定比例位置，向下生长而非居中跳动；专用 Clipboard Viewer 为独立固定比例窗。*注：默认最大可见行数及精确行高随主题变化，官方未公布单一固定 px → **未验证**。* | [Alfred Help — Clipboard](https://www.alfredapp.com/help/features/clipboard/) |

### 2.3 Clavis 面板高度策略与精确公式

**核心决策**：区分**两类页面模式**，绝不让 2 项 Leader 子页继承剪贴板的高大窗口：

1. **轻量指令页（Leader 主菜单、Leader 子菜单如 AI 改写、快捷确认页）→ 严格跟随内容高度（Content-Hugging）**；
2. **双栏/浏览页（剪贴板历史、代码片段、术语表、Agent 会话）→ 固定工作区高度（默认 `540 pt`，可拖动调高，范围 `420–720 pt`）**。

#### A. 轻量指令页高度公式

先将 Leader 动作行从「独立描边大卡片」收敛为 **macOS 原生平铺行**（去外边框，保留悬停/选中圆角底 `6 pt`，行高由 `42+6=48 pt` 优化为 **`38 pt` + `2 pt` 间距 = `40 pt/项`**，密度更像原生 macOS 菜单且横向留白感大幅收敛；若保留现有卡片形态则 `rowStride = 48 pt`）：

$$\text{PanelHeight}(N) = \text{clamp}\!\Big(\; H_{\text{header}} + P_{\text{top}} + P_{\text{bottom}} + \max(N, 1)\cdot H_{\text{row}} + \max(N-1, 0)\cdot G_{\text{row}} + H_{\text{footer}},\; H_{\min},\; H_{\max} \;\Big)$$

| 参数 | 推荐紧凑值（平铺行） | 兼容现行卡片值 | 说明 |
|---|---|---|---|
| $H_{\text{header}}$（顶栏：品牌 + 面包屑 + 上下文胶囊） | `40 pt` | `44 pt` | 含 `1 px` 底部分割线 |
| $P_{\text{top}} + P_{\text{bottom}}$（列表区上下内边距） | `8 + 8 = 16 pt` | `12 + 12 = 24 pt` | 呼吸感充足但绝无大片留白 |
| $H_{\text{row}}$（单动作行高） | `38 pt` | `42 pt` | `13 pt` 标题居中 + `22×22 pt` 键帽 + `16×16 pt` 图标 |
| $G_{\text{row}}$（行间距） | `2 pt` | `6 pt` | 平铺行 `2 pt` 即可清晰区分选中胶囊 |
| $H_{\text{footer}}$（底栏快捷键提示） | `34 pt` | `38 pt` | 含 `1 px` 顶部分割线 |
| $H_{\min}$（空态/1 项最小高度） | `140 pt` | `156 pt` | 即使空态也能完整放下空态图标 + 1 行提示 |
| $H_{\max}$（轻量指令页上限） | `438 pt`（最多展示 `9` 项，超出滚动） | `508 pt`（最多 `8` 项） | 保证永不占满整屏，不越过屏幕高度 `60%` |
| **宽度（轻量 Leader 页）** | **`560 pt`**（或双栏页维持 `780 pt`） | 维持 `720 pt` | 560 pt 可彻底消除 2 字标题右侧 `560 pt` 空洞；若要与主面板零横向抖动则维持 `720 pt` 仅缩高度 |

#### B. 典型条目数高度速查表（直接验证 `2-leader-submenu.webp`）

| 页面与条目数 $N$ | 推荐紧凑公式高度 | 兼容现行卡片公式高度 | 相比占满屏（`540–800 pt`）减少死白 |
|---|---|---|---|
| 空态（$N=0$） | `140 pt` | `156 pt` | 居中展示空态图标 + 文案，零死白 |

#### C. Push / Pop 切换防跳动规范（MyGo / AppKit `NSPanel` 实现要点）

1. **严格顶边锚定（Top-Anchored Frame）**：修改 `NSPanel` 高度时，保持 `top = oldFrame.y + oldFrame.height` 不变，只重算 `newY = top - newHeight`；用户眼睛盯住的标题栏和第一行键帽坐标 `0 px` 位移。
2. **短阻尼高度插值**：高度变化 `|ΔH| > 4 pt` 时做 **`120 ms cubic-bezier(0.2, 0.9, 0.3, 1.0)`** 平滑插值（“减少动态效果”下切为 `0 ms`）；搜索过滤输入时加 **`40 ms` 高度收缩防抖**（增长立刻响应、收缩延迟 `40 ms`），避免每敲一个字母窗口上下高频抖动。
3. **主面板模式切换防闪烁**：从轻量 Leader（`288 pt`）切入剪贴板双栏（`540 pt`）时，先设置目标高度再淡入内容（`80 ms`），避免半截滚动条闪现。
