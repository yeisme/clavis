## 0. 现状诊断与不可回退的硬约束

### 0.1 对照 Maccy（`/tmp/clavis-clipboard-vs-maccy.webp`）的差距解剖

对比实机 Maccy 截图与 Clavis 当前 `uiapp/` 实测代码，Clavis 在能力深度（AI OCR / 翻译 / 标注 / Markdown 预览 / Vault TTL 隔离）上已经明显领先，但在高频“呼出 → 扫一眼 → 秒贴”的日常体验上，与 Maccy 存在 **6 处结构性差距**：

| 维度 | Maccy（对照图实测） | Clavis 现状（代码实测） | 体感落差 |
|---|---|---|---|
| **垂直 Chrome 损耗** | 约 `96–104 pt`（单行顶搜 `~36 pt` + 底菜单；无多 Tab、无常驻统计带） | **`206 pt`**（`headerHeight 40` + `searchRowHeight 52` + `clipboardStatsBandHeight 54` + `footerHeight 44` + `omniboxChrome 16`，见 `uiapp/tokens.go:169-172`、`uiapp/layout.go:75-96`） | 面板打开前近 1/3 高度已被外框吃掉 |
| **列表密度与步进** | 文本行 `~28–30 pt`、图片行 `~44 pt`；单屏直览 **17–20 条** | 统一双行 `rowHeightOmnibox = 44 pt` + `rowGap = 4 pt` = **`48 pt/行`**；默认 `MaxVisibleResults = 8`，单屏仅 **7–8 条** | 找第 10 条历史必须滚屏，扫视效率不到 Maccy 一半 |
| **行内信息呈现** | 单行显示，换行以 **`↵`** 内联标出，长 URL/路径走**中间截断**（`file:///Users/.../ps-proxy-bundle-20261115.tar.gz`），右侧常驻 **`⌘1..⌘9`** | 第二行重复显示 `来源 App · 时间 · 行数`；标题仅尾部截断（长路径/URL 前缀全撞车）；`⌥1..9` 必须按住 `⌥` 才显露 | 同域名链接、同目录文件路径靠左看难以区分；数字直选不可见 |
| **预览区工具与元数据** | 顶部极净 4 枚单色图标（OCR / Pin / Copy / Delete），中间全幅无框画布，底部 `1px` 分割线 + 紧凑对齐元信息清单（含真实应用图标、首次/上次复制时间、复制次数） | 预览区纵向堆叠 **4–5 层碎片栏**：`预览标题+MD切换` → `来源+置顶胶囊` → `缩放/标注/OCR` 或 `字数/展开` → `preview-copy-bar` → `renderPreviewActionHints` | 视觉层次破碎，元数据与操作按钮反复抢占垂直空间 |
| **默认确认语义** | `↵` 直接粘贴（可配），`⌥↵` 纯文本粘贴，单击=粘贴，心智完全一致 | 点击行触发粘贴（`EventActivateClipboardItem`），但键盘 `↵` 却是复制（`copy`）、`⌘↵` 才是粘贴（`paste`）（`pkg/core/engine/capsule.go:1191-1192`、`uiapp/capsule_view.go:1179`） | 鼠标点击与键盘回车默认动作分裂 |
| **上下文菜单 (`⌘K`)** | 右键/操作不挤压列表；底部带 `全部清除 (⌥⇧⌘⌫)` 与 `偏好设置 (⌘,)` | `⌘K` 把动作卡片直接插在列表上方，**把整个列表往下顶**（`capsule_view.go:977-981`）；不支持行右键菜单；缺少“全部清除”快捷入口 | 开菜单时视线大幅跳动，鼠标用户缺少右键心智 |

### 0.2 不可回退的 6 条性能硬约束（一票否决线）

以下约束来自已验收的 jank 修复（`85cfa27`、`4daa15d`、`fe21df5`、`61abdae`、`79d325b`）与 [`clipboard-jank-review.md`](clipboard-jank-review.md)。**下面所有三套设计方案都必须 100% 满足全部 6 条，任何设计细节不得使其回退**：

1. **列表行强制平坦（`85cfa27`）**：剪贴板列表永远 `ObliqueRows = false`（禁止逐行 `RotateY` / `TranslateZ` 3D 倾斜），上下切换时未选中旁观行像素变化率必须维持 **`0.0%`**。
2. **行 Key 稳定 + 零行级进场动画（`85cfa27`）**：每行强制绑定稳定 Key（如 `"clip:" + item.ID`），禁止挂载 `rowEnterAnimation` 等逐行位移过渡，过滤/Pin/刷新不得触发整列跳动。
3. **选中态 `0 ms` 即时切换（`85cfa27`）**：剪贴板列表禁用 `AnimateColor`（禁止 80ms 淡入淡出导致双蓝条重影与左右栏 1–2 帧撕裂），左选框与右预览必须同帧 `t = 0 ms` 同步切换。
4. **指针/键盘 2px 位移仲裁（`4daa15d`、`61abdae`）**：保留 `inputMode` + `pointerArmedPos`（曼哈顿位移 `>= 2 pt` 才解锁 `hoverSelect`），且仅当选中项离开可见视口才调用 `ScrollIntoView`，静止鼠标下连按 `↓` 回弹次数 **`== 0`**。
5. **热路径零深拷贝 + 有界缓存 + 异步媒体解码（`fe21df5`、`79d325b`）**：
   - 切选行继续走 COW 不可变切片（禁止 `cloneState` 深拷贝）；
   - 新增的 `↵` 替换与中间截断计算必须沉淀进 `rowMetaCache`（仅嗅探前 `2048 B`），严禁每帧对 256 KiB 长文本重跑扫描；
   - 文本预览首屏继续锁定 **60 行上限** + `previewTextCache`（按需展开至 200 行）；
   - 缩略图与原图解码全异步（UI 线程零 `os.ReadFile` / 解码阻塞），原图解码 **`<= 120 ms` 宽限期内禁止闪出“正在加载图片…”文本**；
   - 目标基准守恒：Apple M4 下 `BenchmarkClipboardSwitch/typical < 6.0 ms`（`< 450 KB/op`），`large (256 KiB) < 8.3 ms`（守住 120Hz 预算）。
6. **切行不改原生窗口尺寸（`85cfa27`）**：上下切换不同类型条目（文本 ↔ 图片 ↔ 文件 ↔ 颜色）时，Capsule 窗口宽高**绝对恒定**，禁止因媒体画布增高引发原生窗口 resize 闪烁。

## 1. 三套可选完整设计方案对比

为避免“拍脑袋只给一版”，下面提供三套定位截然不同、均可直接落地的完整设计方案，全部给出精确尺寸与工程取舍。

### 1.3 推荐选型结论

**推荐落地「方案 B 为主干 + 吸收方案 A 的独立直达精简顶栏与实心蓝可选主题」**：
- **为什么押方案 B**：Clavis 1.0 不是单一剪贴板工具，而是 6-Tab 统一键盘启动器；方案 B 零破坏现有 Omnibox 骨架、直接复用 `ui.SplitPercent` + `ui-state.json` 持久化与 `clipboard_stats_view` 数据管线，同时把单屏密度提升 **+60%（7–8 条 → 12–14 条）**、彻底消灭预览区 4 层碎片工具条与底栏碰撞。
- **如何无痛吸纳方案 A**：用户通过**全局剪贴板直达热键（`⇧⌘V`）**呼出时，自动进入 **Clipboard Focus Header**（折叠 `40 pt` 6-Tab 顶栏，并将前 9 条快捷键切换为 `⌘1..⌘9`），按 `⌘←/→` 或点左上角返回图标即可一键回到完整 Omnibox。如此一来，高频纯剪贴板用户的体验与方案 A/Maccy 几乎等价。
- **为什么不选方案 C 作默认**：macOS 下多显示器边缘定位 + `NSPanel` 双窗同步/动态横扩复杂且易与 IME/焦点抢占冲突，违背 1.0 稳定优先原则；但方案 B 保留 `⌘I` 折叠预览后可选收缩为单栏列表（保留同宽或可选记住单栏宽），已覆盖 90% 的轻量化诉求。

### 2.1 双入口心智模型

| 入口路径 | 触发方式 | 面板模式 | 顶栏行为 | 设计目的 |

### 2.2 信息职责严格分层（消灭跨区重复）

1. **左栏（列表）只负责「快速识别与定位」**：
   - 最多展示 4 个原子信号：**类型图标/缩略图** + **单行内容摘要（含 `↵` 与智能截断）** + **置顶标记** + **右侧索引/极简时间**。
   - 严禁把完整来源名、分辨率、文件字节数、多行预览堆在左栏（除非用户显式选择“舒适双行模式”）。
2. **右栏（预览）只负责「深度辨认、微变换与诊断元数据」**：
   - 上部：上下文微工具条（格式/缩放 + 4 枚高频动作图标）；
   - 中部：100% 不透明内容渲染区（文本 / Markdown / JSON / 代码 / 缩放图片 / 色卡 / 文件清单）；
   - 底部：Maccy 风格固定元信息清单（应用真图标、维度/字数、大小、首次/上次时间、复制次数）。
3. **底栏只负责「主操作锚点与全局状态」**：
   - 左对齐最多 4–5 组核心键帽提示（随选中类型微调，超出项收进 `⌘K`）；
   - 右对齐全局控件：`⌥⇧⌘⌫ 清空`、`⌘I 预览开关`、`⌘K 动作`。
4. **安全与运营边界（严格对齐 1.0）**：
   - 密码与凭据引用留在 **管理 → 安全（Settings → Security）**，绝不混入剪贴板历史列表；
   - 当用户通过 Vault 执行 User-Only TTL 复制时，仅在顶栏显示非明文状态胶囊（如 `🔒 Production DB · 24s [立即清空]`），不暴露正文、不写 SQLite 历史。

### 3.2 单行文本预处理与「语义中间截断」规范

所有计算**必须封装在 `rowMetaCache`（`uiapp/clipboard_row.go`）内**，按 `{ItemID, ContentLen, ContentHeadHash, WidthBucket}` 缓存，仅扫描前 `2048 B`（`clipboardSniffBytes`），严禁每帧分配大字符串：

1. **多行折叠符号（参考 Maccy）**：
   - 去除首尾空白；将内部 `\r\n` / `\n` 替换为视觉标记 **` ↵ `**（渲染时可用 `text.tertiary` 淡灰色与正文区分，多连续空行合并为最多两个 `↵↵`）；将 `\t` 与连续空格折叠为单空格。
   - 例：`Agent 调度暂未开放\n这个控制接口...` → `Agent 调度暂未开放 ↵ 这个控制接口...`，一眼知道它是多行块而非单行词组。
2. **语义感知截断规则**：
   - **URL（`http://` / `https://`）**：保留协议后的域名 + 首段路径 + `…` + 末尾 `18–24` 字符（路径文件名/ID/Query 尾巴），例：`https://github.com/yeisme/…/pull/142`。
   - **文件路径（`/`、`~/`、`file://`）**：保留前段目录（约 40% 宽）+ `…` + 末尾文件名与扩展名（约 55% 宽），例：`file:///Users/yeisme/…/clavis-0.1.0-arm64.dmg`。
   - **长单行标识/命令行（无空格且 > 36 字符，或 Shell 命令）**：前 60% + `…` + 后 35%，保留结尾参数/校验位。
   - **普通自然语言 / 多行正文**：标准尾部截断（保留开头可读语义，配合 `↵`）。
   - **搜索命中态优先级**：若存在 `MatchedIndices`（搜索关键词命中在文本中后段），**自动窗口居中到首个命中词附近**（左右各保留 `…`），确保用户永远看见自己搜到的高亮词！

### 4.1 搜索框与检索管线

- **即时首帧 + 异步 FTS5**：严格保持现有架构（`pkg/core/engine/clipboard_search_test.go` 验证的契约）：

## 5. 键盘流（Keyboard Flow · macOS 1.0）

### 5.1 解决核心分裂：确认键默认行为契约

现有代码存在 `点击=粘贴` 与 `Enter=复制 / ⌘Enter=粘贴` 的分裂。本设计统一为 **可配置、默认符合 Maccy 效率直觉** 的二元互补模型：

- **默认配置 `clipboard.enter_action = "paste"`（推荐）**：
  - `↵ (Enter)` 与鼠标单击均执行**直接粘贴到上一个前台应用**；

- **无 Accessibility 权限自动降级**：若 macOS 未授予辅助功能权限，按 `↵` 不报错阻塞，自动完成复制并弹出 1.4s HUD：「已复制（开启辅助功能后可自动粘贴）」。

## 6. Pin 与分类体系（Pin & Categories）

### 6.1 Pin 分段与排序设计

参考 Maccy 对置顶条目的高辨识处理，默认采用 **「顶部分段 + 轻眉标」** 组织：

1. **列表视觉结构**：
   - 当存在已置顶条目时，列表分为两段：**`置顶 · N`**（`22 pt` 高，左对齐 `10 pt Semibold text.tertiary` + 右侧延伸 `1px hairline`）与 **`最近 · M`**（同规格轻眉标）；
   - 若无任何置顶条目或当前处于 `is:pinned` 过滤态，不渲染冗余分段眉标，零空间浪费。
2. **排序与淘汰保护**：
   - 置顶段内默认按「置顶时间倒序（最新置顶在最前）」排列；
   - **淘汰豁免（延续现有逻辑）**：达到 `MaxHistoryItems`（默认 `200`）或 `MediaQuotaMB`（默认 `512 MB`）触发 LRU 清理，或执行 `⌥⇧⌘⌫`「清空历史」时，**所有 `IsPinned == true` 的条目强制豁免保留**；
   - 位置可配置：`clipboard.pin_position = "top"`（默认） / `"bottom"`（对齐 Maccy 偏爱近期历史始终占据 `⌘1..5`、Pin 放底部的习惯） / `"inline"`（仅标图钉图标不拆段）。
3. **Pin 变更时的焦点稳定性**：
   - 按 `⌘P` 置顶/取消置顶时，条目在 SQLite 与内存列表即时乐观更新，**选中焦点锚定在原行索引位置（或跟随该条目，可在行为中统一约定：默认保持跟随该条目并滚入视口，避免用户刚 Pin 完不知条目的去向）**，且绝不触发整列重建动画。
4. **Pin 与 Snippets 的清晰产品边界（不做过度设计）**：
   - Maccy 支持给单个 Pin 绑自定义单字母快捷键（因为 Maccy 没有独立的代码片段系统）；
   - Clavis 已经拥有完整的 **Snippets（`;trigger` 展开 + 动态变量 + Prompt Composer）**；
   - 因此 **Pin 定位为“短期高频临时固定”（几小时～几天内反复用的截图/链接/命令）**，同时在 `⌘K` 动作菜单提供一键 **「转为代码片段 (Save as Snippet)」**，帮用户把长期沉淀文本自然升格到 Snippets，而不把剪贴板做成第二套 Snippets。

### 6.2 分类体系（严格对齐 1.0，零手工负担）

| 分类维度 | 机制 | 具体类目 | 1.0 边界说明 |
|---|---|---|---|
| **一级：自动内容类型** | 零配置自动识别（复用 `clipboard.Kind` + `clipboard_row.go` 2KB 头部嗅探） | `全部`、`置顶`、`文本`、`图片`、`文件`、`链接`、`代码`、`颜色` | 前 6 项常驻单行筛选条，`代码` / `颜色` 可通过搜索 `type:code` / `type:color` 或展开筛选命中 |
| **二级：自动来源应用** | 基于 `SourceAppName` / `SourceBundleID` 自动聚合 | 预览区点击来源应用名即过滤，或输入 `app:<名>` | 极高频开发场景：“找刚才在 Ghostty / Edge / Cursor 复制的内容” |
| **明确不做（1.0 非目标）** | 手工多级文件夹 / 自定义彩色标签（P5 taxonomy） | — | [`scope-1.0.md`](scope-1.0.md) 已明确排除 P5 taxonomy；手工打标违背剪贴板瞬时直觉 |

### 8.2 极端数据与安全隐私边界

1. **超大内容与病态字符串**：
   - **长日志（256 KiB – 1 MiB）**：列表行元数据提取只读前 `2048 B`；预览首屏强制截断 **60 行**，超出部分仅在点击展开时按需分片到 `200 行`，总字节 > 2 MiB 时预览顶部提示「超大文本已截断预览，粘贴/复制仍为完整原文」。
   - **无空格超长串（JWT / Base64 / Data URI）**：列表行强制中间截断，预览区启用字符级折行（Wrap），绝不撑出横向滚动条破坏分栏几何。
   - **RTL / Emoji / CJK 混排**：列表行严格走 MyGo 单行裁切，固定行高（`32 pt`），Emoji 组合字形不得撑高行盒。
2. **隐私与 Password / Vault 红线（不可妥协）**：
   - **自动跳过入库**：延续 `pkg/core/clipboard/filter.go` 全部规则——命中 `org.nspasteboard.ConcealedType`、`TransientType`、`AutoGeneratedType`、`com.agilebits.onepassword` 或 `ExcludedBundleIDs`（1Password、Keychain Access 及用户一键屏蔽的 App）时静默丢弃，**零落盘、零内存缓存、零 Toast 提示**。
   - **User-Only TTL 隔离**：由 Security Vault 或 `⌥⇧⌘C` 发起的敏感复制严格锁定 `ClipboardCopyOriginUser`，Agent 路径返回 `ErrSensitiveCopyUserOnly` / `agent_forbidden`；剪贴板面板绝不展示任何密文正文或 `••••` 星号预览，仅在顶栏提供 TTL 倒计时胶囊与 `[立即清空]` 按钮。
   - **自触发防环**：粘贴/敏感写入前均经 `IgnoreSelfPasteboardChange(seq)` 与 `recentSecretHashes` 拦截，防止自身粘贴操作产生重复条目或将敏感串回写历史。
3. **防误删与清空保护**：
   - **单条删除（`⌘⌫`）**：即时从列表移除并在底栏上方弹出 **`32 pt` 轻撤销条**（`已删除 1 条 · [撤销 ⌘Z]`，持续 `5s`），`5s` 过期或关闭窗口后才彻底从 SQLite & MediaStore 删除，兼顾极速无打断与防误触。
   - **全部清除（`⌥⇧⌘⌫`）**：不弹模态系统对话框（防焦点丢失），在底栏位置原位切换为 **内联二次确认条**（`清空 146 条未置顶历史？（已置顶 2 条将保留） · [取消 Esc] [确认清空 ↵]`，默认焦点在「取消」，防止连按回车误清）。
